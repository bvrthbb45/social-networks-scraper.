# OPSEC Monitor: ניטור חשיפת מידע ברשתות חברתיות

מערכת למחלקת ביטחון מידע, לזיהוי פרסומים **פומביים** של חיילים **שחתמו על הסכמה**, שחושפים מידע רגיש:
מדים וציוד, תצלומים של דברים שנראים מסווגים, ומיקומי יחידות לפי שמות קוד.
כל ממצא הוא אינדיקציה בלבד: **איש ביטחון מידע מחליט**.

> **המאגר הזה צריך להיות פרטי (Private), ולעולם לא יעלה אליו מידע אמיתי.** ראו `docs/data-protection.md`.

## מה המערכת עושה
1. קולטת קובץ Excel (פלטפורמה, שם משתמש, סטטוס פתוח/סגור, תוכן פומבי) ושוללת כל שורה בלי הסכמה בתוקף.
2. מנתחת תוכן **פומבי** של חשבונות **פתוחים** בלבד: טקסט, תמונות ו-OCR, בעבודה מקומית.
3. מציגה ממצאים לבדיקה עם הראיה והסיבה.

## מה היא לא עושה, בכוונה
- לא מתאימה מספרי טלפון לחשבונות. לא מנטרת WhatsApp.
- לא ניגשת לחשבון סגור. לא עוקפת הגנות של פלטפורמות (אין סקרייפינג).
- לא מסיקה מסקנות על אדם בלי בדיקה אנושית. לא שולחת תמונות או טקסט לשירות חיצוני.

## מבנה
```
backend/    FastAPI + SQLAlchemy 2 + Alembic (PostgreSQL)
web/        ממשק עברי RTL (Loop 5)
android/    אפליקציית Android (Loop 7)
docs/       ארכיטקטורה והגנת מידע
scripts/    בדיקת "אין נתונים בגיט" ו-hook
```

## הרצה
```
cp .env.example .env        # למלא סיסמאות ומפתחות (הפקודות בקובץ)
docker compose up --build
curl http://127.0.0.1:8000/health
bash scripts/install-hooks.sh    # חוסם commit של קבצי נתונים
```
בדיקות: `cd backend && pip install -r requirements-dev.txt && pytest`
(עם PostgreSQL: `TEST_PG_URL=postgresql+psycopg://user:pw@host/db pytest`).
