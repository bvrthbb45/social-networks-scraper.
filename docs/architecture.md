# ארכיטקטורה

## זרימת הנתונים
```
קובץ Excel ──► קליטה ואימות ──► [אין הסכמה בתוקף? נדחה]
                                   │
                          סטטוס חשבון: פתוח / סגור / לא ידוע / לא נמצא
                                   │ (פתוח בלבד)
                     תוכן פומבי ──► ניתוח מקומי: טקסט, תמונות, OCR
                                   │
                            מנוע כללים ──► ממצא (ציון, חומרה, סיבה)
                                   │
                           תור בדיקה ──► החלטת איש ביטחון ──► יומן ביקורת
```

## רכיבים (לפי לולאות)
| לולאה | רכיב |
|---|---|
| 1 | ארכיטקטורה, Docker, סכמת מסד נתונים (המסמך הזה) |

| 6 | דוחות, שמירה ומחיקה, לוח בקרה |
| 7 | אפליקציית Android |
| 8 | פריסה on-prem |

## סכמת הנתונים
| טבלה | תפקיד |
|---|---|
| `users` | מפעילי המערכת. תפקיד: `uploader`, `reviewer`, `admin`, `auditor` |
| `audit_log` | יומן ביקורת. **Append-only**: טריגר במסד הנתונים דוחה UPDATE ו-DELETE. משתמש עם היסטוריה לא נמחק, רק מושבת |
| `soldiers` | חיילים. מספר אישי ושם מוצפנים, ו-HMAC לחיפוש בלי פענוח |
| `consents` | ההסכמה החתומה: תקופת תוקף, סטטוס (פעילה / בוטלה / פגה) |
| `accounts` | חשבון חברתי. **`consent_id` חובה**: אי אפשר ליצור חשבון בלי הסכמה, וזה נאכף במסד הנתונים |
| `imports` | כל העלאת Excel: מי, מתי, גיבוב, ספירות דחייה (בלי תוכן שורות) |
| `posts` | תוכן פומבי שנקלט. טקסט מוצפן. **`delete_after` חובה** (אחרי זמן הקליטה) |
| `watchlist_terms` | שמות קוד ואתרים. מוצפנים, עם אינדקס HMAC |
| `findings` | ממצא אוטומטי: סוג, ציון 0 עד 1, חומרה, סיבה וראיה מוצפנות. אידמפוטנטי |
| `reviews` | החלטת בודק: אושר / נדחה / הועבר |

**פלטפורמות נתמכות:** instagram, tiktok, facebook. WhatsApp לא נתמך ונדחה ברמת מסד הנתונים.

## מחיקה
- ביטול הסכמה או מחיקת חייל מוחקים בשרשרת (CASCADE): חשבונות, תוכן, ממצאים והחלטות.
- ממצאים וההחלטות עליהם נמחקים יחד עם התוכן שלהם.
- יומן הביקורת נשמר. הוא לא מכיל מידע אישי או ראיות (`details` ללא PII).

## בידוד רשת (Docker)
מסד הנתונים נמצא ברשת `internal` **בלי ניתוב החוצה**. רק ה-API מחובר גם לרשת החיצונית, ומפורסם ל-`127.0.0.1` בלבד.
הקונטיינרים רצים בלי הרשאות מיותרות (`cap_drop: ALL`, `no-new-privileges`), וה-API במערכת קבצים לקריאה בלבד.
