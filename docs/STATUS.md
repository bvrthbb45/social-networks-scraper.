## גבולות שנקבעו (לא משתנים ללא אישור מפורש)
רק תוכן ציבורי של חשבונות פתוחים בהסכמה חתומה; אין עקיפת הגנות של פלטפורמות; אין התאמת מספרי טלפון לחשבונות; אין וואטסאפ; אין חשבונות סגורים; אין החלטות אוטומטיות על אנשים (בודק אנושי מחליט תמיד); אין שירות AI חיצוני.

## ממתין להחלטת המשתמש
* הפיכת הריפו לפרטי ובחירת שם (ההמלצה: להחליף את "scraper").
* דוגמת כותרות של קובץ האקסל ופורמט רשימת שמות הקוד (המיפוי הנוכחי מבוסס על ניחוש).
* מודל תמונות לזיהוי ציוד/מסמכים (לא נשלח; הממשק מוכן). הלמידה מסדרת תור בלבד ואינה מוסיפה יכולת זיהוי.
* אישור משפטי של נוסח ההסכמה ושל תקופות השמירה.
* החלטות פריסה והפצה לאנדרואיד.

## הרצה מקומית
```bash
# שרת
cd backend && pip install -r requirements-dev.txt && python -m pytest        # עם TEST_PG_URL לבדיקות PostgreSQL
python -m app.cli create-admin EMAIL                                         # מנהל ראשון (מחזיר קישור הזמנה)
# ווב
cd web && npm install && npm run check
TEST_PG_URL=... bash e2e/run.sh                                              # מקצה לקצה בדפדפן אמיתי
```
