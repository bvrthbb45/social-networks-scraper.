# ממשק Web (עברית, RTL)

React + TypeScript + Vite. הממשק כולו בעברית (`src/i18n/he.ts`), עם בדיקות שמונעות מחרוזות לטיניות ותכונות CSS פיזיות (left/right).

## הרצה
```bash
npm install
npm run dev          # שרת פיתוח; /api מועבר ל-http://localhost:8000
npm run check        # בדיקות RTL ועברית, בדיקת טיפוסים, בדיקות יחידה ובנייה
bash e2e/run.sh      # מקצה לקצה בדפדפן אמיתי (דורש TEST_PG_URL ל-PostgreSQL ריק)
```
בצד השרת יש להגדיר `REFRESH_COOKIE_PATH=/api/auth` ו-`ALLOWED_ORIGINS` כשהממשק והשרת נמצאים תחת אותו דומיין (ראו `.env.example`).

## עקרונות אבטחה בממשק
* אסימון הגישה נשמר בזיכרון בלבד (לא ב-localStorage); ההתחברות מתחדשת מ-cookie מסוג httpOnly + SameSite=Strict.
* קישור הזמנה (`/?invite=…`) נלכד בעת טעינת האפליקציה ומוסר מיד משורת הכתובת.
* יציאה אוטומטית אחרי 15 דקות ללא פעילות.
* תמונות ראיה מוסתרות כברירת מחדל; הצגתן נרשמת ביומן הביקורת ואינה נשמרת במטמון.
* פעולות הרסניות (ביטול הסכמה, מחיקת חייל, מחיקת מונח, איפוס פרטי כניסה) דורשות אישור מפורש.
* ההרשאות נאכפות בשרת; הממשק רק מסתיר מה שהתפקיד לא יכול להשתמש בו.
